# YtGrab

Простое Android-приложение для скачивания видео с YouTube и TikTok (и любых сайтов, поддерживаемых yt-dlp).

Современный Material 3 интерфейс с динамическими цветами Material You, русский и английский языки.

## Возможности

- **Скачивание видео** по ссылке: вставка из буфера, кнопка «Поделиться» из YouTube/TikTok, открытие ссылок из браузера
- **Выбор формата**: полный список форматов с разрешением, fps, кодеком (H.264 / VP9 / AV1) и точным размером файла; аудиодорожка подбирается автоматически под контейнер (AAC для MP4, Opus для WebM)
- **Плейлисты**: быстрый список роликов с чекбоксами, выбор пресета качества и кодека, пакетная загрузка в очередь
- **Фоновая загрузка** через foreground service с уведомлением о прогрессе, скорости и оставшемся времени; отмена и повтор
- **Настройки**: подпапка в «Загрузках», подпапки по платформам, встраивание метаданных/обложки, тема оформления
- **Обновление yt-dlp** из приложения (Настройки → Движок) — если YouTube что-то поломал, обновление движка обычно чинит

## Установка

Готовый APK (только arm64-v8a, Android 12+) — на странице [Releases](../../releases).

1. Скачайте APK с последнего релиза
2. Откройте его на телефоне → разрешите установку из этого источника
3. Готово; файлы сохраняются в `Download/YtGrab`

> APK из GitHub Actions (артефакты сборки) подписан debug-ключом; APK из релизов — личным ключом разработчика. Обновление с debug-подписи на релизную требует переустановки.

## Сборка из исходников

Требуется JDK 17 и Android SDK (платформы 36/37). Локальные пути заданы в `local.properties` (не коммитится).

```bash
./gradlew :app:assembleRelease   # релизный APK: app/build/outputs/apk/release/
./gradlew :app:assembleDebug     # отладочный APK
./gradlew :app:testDebugUnitTest # unit-тесты
```

Ключ подписи: `ytdl.keystore` + `keystore.properties` (в корне проекта, в git не попадают —
сохраните их, чтобы будущие обновления ставились поверх установленной версии).

CI: `.github/workflows/build.yml` собирает APK на каждый push в GitHub Actions.

## Архитектура

- Kotlin + Jetpack Compose + Material 3, single-activity, MVVM
- Движок: [yt-dlp](https://github.com/yt-dlp/yt-dlp) через [youtubedl-android](https://github.com/JunkFood02/youtubedl-android) (бандлит Python + yt-dlp в APK) + FFmpeg для склейки потоков
- Очередь загрузок: `DownloadRepository` (StateFlow) + `DownloadService` (foreground, dataSync)
- Выбор формата: `-J` JSON → фильтрация/группировка форматов → точный `-f <video>+<audio>`
- Настройки: DataStore Preferences

## Примечания

- Приложение распространяется в обход Google Play (политика магазина запрещает загрузчики YouTube) — только ручная установка APK
- Плейлисты: у отдельных роликов размер заранее неизвестен (yt-dlp отдаёт размеры только при полном извлечении), поэтому для плейлистов выбирается пресет качества, а не конкретный формат
- Приватные/age-restricted видео и большинство роликов TikTok со включённым «скрытым» профилем потребуют cookies — в v1 не поддерживается
- Список загрузок хранится в памяти: если система убьёт процесс приложения, незавершённые задачи пропадут (завершённые файлы остаются в «Загрузках»)

```
├── MainActivity.kt         # приём share/view интентов
├── data/
│   ├── FormatBuilder.kt    # чистая логика выбора форматов (unit-тесты)
│   ├── YtDlpEngine.kt      # обёртка над youtubedl-android + парсинг JSON
│   ├── DownloadRepository.kt # очередь задач
│   └── SettingsRepository.kt # DataStore
├── service/DownloadService.kt # foreground service + уведомления
└── ui/                     # home, playlist, downloads, settings, theme
```
